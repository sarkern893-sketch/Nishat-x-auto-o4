Telegram Auto-Post Bot — Deployment Guide
==========================================

এই প্যাকেজে bot-এর সম্পূর্ণ code আছে। নিরাপত্তার জন্য Telegram user session file
distribution ZIP-এর মধ্যে রাখা হয়নি; production data directory-তে নিজে রাখতে হবে।

প্রয়োজনীয় environment variables:

BOT_TOKEN              BotFather থেকে পাওয়া bot token
ADMIN_IDS              আপনার Telegram numeric user ID
TELEGRAM_API_ID        my.telegram.org-এর API ID
TELEGRAM_API_HASH      my.telegram.org-এর API Hash
TELEGRAM_PHONE         +880... format-এ Telegram user account-এর নম্বর
TELEGRAM_SESSION       telegram_user
DATA_DIR               Replit-এ data, Railway Volume ব্যবহার করলে /data

SOURCE_CHANNELS এবং DEST_CHANNEL_ID আর লাগবে না।
Source ও Destination bot-এর admin panel থেকেই যোগ করতে হবে।

Replit:
1. Bot workflow চালু করুন।
2. Telegram-এ bot-কে private message করে /start পাঠান।
3. 📡 চ্যানেল সেটিংস থেকে Source এবং Destination যোগ করুন।
4. 📝 অটো পোস্ট → 🟢 চালু করুন।
5. ⚙️ সেটিংস → 📇 Personal তথ্য থেকে নিজের username, ফোন, email ও Telegram link দিন।
6. ⚙️ সেটিংস → 🔁 Forward সেটিংস থেকে target Group, repeat সংখ্যা ও interval সেট করুন।

Railway:
1. Dockerfile দিয়ে এই folder deploy করুন।
2. সব প্রয়োজনীয় environment variables যোগ করুন।
3. একটি persistent Volume /data path-এ mount করুন।
4. telegram_user.session ফাইলটি /data/telegram_user.session হিসেবে রাখুন।
5. Destination channel-এ bot-কে administrator করুন।
6. Source channel পড়ার permission Telegram user account-কে দিন।
7. Forward target Group-এ bot-এর message পাঠানোর permission দিন।
8. Service-টি always-on worker হিসেবে চালু রাখুন।

নিরাপত্তা:
- telegram_user.session, BOT_TOKEN এবং TELEGRAM_API_HASH কাউকে দেবেন না।
- এগুলো GitHub বা public storage-এ upload করবেন না।
- Session হারালে আবার Telegram OTP ও 2FA দিয়ে login করতে হবে।

নতুন workflow:
- Original layout রেখে সীমিত editing ও emoji formatting হবে।
- Source-এর personal তথ্য আপনার সেট করা তথ্য দিয়ে replace হবে।
- Edited post আগে আপনার Channel-এ publish হবে।
- এরপর আপনার Channel-এর edited message native forward হিসেবে Group-এ যাবে।
- Repeat count ও repeat interval Admin Panel থেকে নিয়ন্ত্রণ করা যাবে।
